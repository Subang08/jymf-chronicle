## 第一卷 · 创世与神话

### 第一章：创世神话
- 时间尚未流淌的虚无之中，**原初之炎**与**永恒之冰**相互碰撞，迸发出第一缕**秩序之光**。
- 这光芒凝结为**众星之母**。她以自己的身躯化为**艾尔德兰大陆**；用**肋骨**造出**巨龙**作为世界的守护者；用**泪水**造出**精灵**作为美的见证者；用**热血**造出**人类**作为可能的承载者。
- 巨龙背离守护职责，其中一部分堕入贪婪与毁灭，被称为**彩色龙**。
- 众星之母降下**圣光之矛**，将最大的恶龙钉入地心，其骸骨化为**龙骨山脉**。
- 如今，众星之母沉睡于**世界之核**：祂的呼吸形成**地脉魔法**，祂的梦境编织着**命运本身**。

### 第三章：职业详解（10 职业）

**法师（Wizard）**
- 核心：智力 · 法术书 · 准备施法
- 八大学派：防护、咒法、预言、附魔、塑能、幻术、死灵、变化
- 进阶：大法师、元素使、时空学者
- 弱项：体质薄弱、近战完全无能
- 初始装备包：法杖 + 法术书（含6个1环法术）+ 普通长袍 + 材料包

**术士（Sorcerer）**
- 核心：魅力 · 血脉施法 · 无需准备
- 血脉源：龙脉、精灵血脉、恶魔契约、混沌之力
- 特点：法术数量少但强度高、可以超魔
- 弱项：法术选择极少、稳定性差
- 初始装备包：法杖 + 普通长袍 + 龙鳞护符（或血脉信物）+ 材料包

**战士（Fighter）**
- 核心：力量/敏捷 · 所有武器与护甲
- 子类：武器大师、盾卫者、勇士
- 特点：战斗续航能力极强、可穿戴任何护甲
- 弱项：无超凡手段、面对魔法时脆弱
- 初始装备包：链甲 + 长剑 + 盾牌 + 普通弓 + 20支箭；或 皮甲 + 巨剑 + 两把手斧

**游侠（Ranger）**
- 核心：敏捷/感知 · 双武器/弓箭
- 子类：猎人、驯兽师、守望者
- 特点：地形适应、与自然生物交流
- 弱项：输出不如纯战士和法师
- 初始装备包：皮甲 + 长弓 + 20支箭 + 两把短剑；或 链甲衫 + 战斧

**游荡者（Rogue）**
- 核心：敏捷 · 潜行、暗杀、开锁
- 子类：刺客、盗贼、诡术师
- 特点：爆发力极强、躲藏能力顶尖
- 弱项：正面战斗能力弱
- 初始装备包：皮甲 + 两把匕首 + 盗贼工具 + 短剑；或 轻弩 + 20支矢

**牧师（Cleric）**
- 核心：感知 · 信仰施法
- 领域：生命、战争、知识、诡术、自然、光、暗
- 特点：治疗+伤害兼备，可穿戴中甲
- 弱项：缺乏位移和控场法术
- 初始装备包：链甲 + 钉头锤 + 圣徽 + 木盾；或 皮甲 + 战锤

**圣骑士（Paladin）**
- 核心：魅力/力量 · 誓言施法
- 誓言：奉献、古贤、复仇、征服
- 特点：重甲+治疗+光环，对抗邪恶时有绝对优势
- 弱项：誓言约束严格，违背会失去力量
- 初始装备包：链甲 + 长剑 + 盾牌 + 圣徽；或 板甲（仅限起始金币足够）

**野蛮人（Barbarian）**
- 核心：力量/体质 · 狂怒
- 子类：狂战士、图腾战士
- 特点：血量最厚、输出恐怖、免疫部分伤害
- 弱项：战斗后极度虚弱、不能穿重甲
- 初始装备包：皮甲 + 巨斧 + 两把手斧；或 长矛 + 盾牌

**德鲁伊（Druid）**
- 核心：感知 · 自然施法
- 子类：大地结社、月之结社、梦境结社
- 特点：变形能力、自然法术、治疗与控场兼备
- 弱项：金属禁忌、城市中受限制
- 初始装备包：木盾 + 木杖 + 草药包 + 德鲁伊法器

**吟游诗人（Bard）**
- 核心：魅力 · 音乐施法
- 学院：勇气、学识、剑舞、魅惑
- 特点：全能型选手，擅长社交与信息收集
- 弱项：输出能力有限
- 初始装备包：皮甲 + 长剑 + 乐器 + 匕首；或 轻弩 + 20支矢

### 第四章：魔法系统
- 法术等级：戏法 → 1环 → 2环 → 3环 → 4环 → 5环 → 6环 → 7环 → 8环 → 9环 → 传奇法术
- 施法机制：
  - 奥术施法者每日需记忆法术（法师）或消耗法术位（术士）
  - 神术施法者通过祈祷获得当日法术
  - 法术可超魔增效（增远、增广、瞬发等）
- 禁忌魔法：
  - 死灵系（部分法术）：涉及操控灵魂与死者
  - 惑控系（部分法术）：涉及强制操控心智
  - 恶魔召唤：极易导致施法者死亡或堕落
  - 时间魔法：极度危险，可能引发时空悖论

## 第七卷 · 战斗与死亡规则

### 第一章：战斗基本机制
1. **先攻轮**：由敏捷与反应速度决定行动顺序
2. **行动类型**：标准动作（攻击/施法）+ 附赠动作（移动/次要动作）+ 反应（应对攻击）
3. **命中判定**：你的攻击加值 vs 对方护甲等级（AC）
4. **伤害计算**：武器/法术基础伤害 + 相关属性加成
5. **豁免判定**：抵抗法术、毒素、陷阱等

### 第二章：负面状态

| 状态 | 效果 |
|---|---|
| 震慑 | 无法行动，自动失防 |
| 昏迷 | 失去意识，直至受伤或唤醒 |
| 束缚 | 移动为0，攻击有劣势 |
| 麻痹 | 全豁免劣势，所有攻击自动暴击 |
| 中毒 | 每回合受持续伤害，所有判定有劣势 |
| 恐慌 | 必须远离恐惧源，无法主动靠近 |
| 魅惑 | 无法攻击施法者，对施法者友善 |
| 力竭（6级） | 1-6级递减效果，6级死亡 |

### 第三章：死亡与损伤
- **重伤濒死**：生命归零时进入濒死状态，需进行生死豁免
- **永久损伤**：断肢、内脏损伤、重度烧伤等，可能无法恢复
- **死亡**：无复活魔法（传奇级以下），新角色或读档
- **创伤与心魔**：长期战斗可能导致 PTSD 或性格扭曲

## 第十四卷 · 语言与文字系统

### 第一章：活语言

| 语言 | 主要使用者 | 文字系统 | 特征 |
|---|---|---|---|
| 通用语 | 全人类及跨种族贸易 | 通用字母（源自古代帝国） | 大陆最常用，不同王国口音差异极大 |
| 精灵语（高等） | 高等精灵、贵族 | 精灵花体符文 | 优雅多义，一首诗可有七种解读 |
| 木精灵语 | 木精灵、德鲁伊 | 树皮刻痕符号 | 与鸟兽鸣叫相通，非精灵极难模仿 |
| 矮人语 | 矮人、秘银兄弟会 | 棱角符文（刻于石上） | 粗犷有力，每个词都有"凿刻"感 |
| 龙语 | 龙族、龙裔、高阶法师 | 龙爪印痕（灼刻体） | 每个字都蕴含微弱魔力，误读可引发爆炸 |
| 兽人语 | 半兽人、荒原部落 | 骨刻符号 | 简单直接，约400个词汇，多数为战斗相关 |
| 地底通用语 | 卓尔、地精、黑暗生物 | 触感符号（盲文式） | 在完全黑暗中通过触摸读取 |
| 深渊语 | 恶魔、邪教徒 | 扭曲熔岩体 | 正常生物念出会口腔溃烂，需意志豁免 |

### 第二章：死语言与古代文字
- **创世符文**：众星之母创世时留下的原始文字，每个符文都是一个独立的概念（如"火""生""死"），现存仅12枚可辨识。铭刻在神器上的根源力量。
- **帝国古语**：帝国纪元泛大陆时代的官方语言，现代通用语由其简化而来。所有古代遗迹的铭文和法术书多以此书写。法师必修科目。
- **巨人语**（已失传）：巨人种族留下的符文系统，无人能完全解读，据信记载着元素位面的坐标。

### 第三章：方言与俚语
- 晨曦王国口音：元音拉长，语速缓慢，被认为"最标准"。
- 北境口音：辅音生硬，短促有力，词汇中夹杂矮人语借词。
- 南方联合王国口音：尾音上扬，大量来自沙漠种族的外来词。
- 冒险者俚语：「啃龙骨」意为做高风险低回报的事；「点蜡」意为替人挡刀。
